# 🧱 Dirigo (Library)

> **Dirigo is a library mod. It does nothing on its own.**  
> Library mod required for CinderStride and other Drahlek mods. Adds no gameplay features.

---

## ⚠️ Important

**This is NOT a content mod.**

* Adds **no gameplay features**
* Adds **no items, blocks, or mechanics**
* Only required as a **dependency for other mods**

> If you install this alone, nothing will change — this is expected.

---

## 🔗 Used By

* [CinderStride](https://modrinth.com/project/cinderstride) – Walk on lava with temporary basalt paths  
* [HearthGuard](https://modrinth.com/mod/hearthguard) – Mobs fear campfires  

More mods will depend on Dirigo over time.

---

## 🧠 What Dirigo Provides

* Event system (publish/subscribe)
* Tick-based scheduler
* Config system with validation
* Server → client config sync
* Shared utilities for cross-mod compatibility

---

## 🧩 Compatibility

* Fabric and NeoForge
* Lightweight and safe to include

---

## 📦 Installation

Only install if another mod requires it.

1. Download correct version  
2. Place in `mods` folder  
3. Launch Minecraft  

---

## ❓ FAQ

**Why does nothing happen?**  
Because it’s a library.

**Can I remove it?**  
Yes, unless another mod depends on it.
